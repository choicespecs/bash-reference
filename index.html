Script structure

Every script should start with a shebang and, for most scripts, “strict mode”. Keep logic inside functions and call main at the bottom.

#!/usr/bin/env bash
# my-script.sh — one-line description of what it does
set -euo pipefail

readonly SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

usage() { echo "Usage: $(basename "$0") <arg>"; }

main() {
  [[ $# -ge 1 ]] || { usage; exit 1; }
  echo "Hello, $1"
}

main "$@"
LineMeaning
#!/usr/bin/env bashFind bash on PATH. More portable than #!/bin/bash, which on macOS is the old bash 3.2.
set -eExit right away when a command fails.
set -uTreat unset variables as an error.
set -o pipefailA pipeline fails if any command in it fails, not just the last.
main "$@"Pass every argument through to main, unchanged.

Running a script

chmod +x my-script.sh     # make executable (once)
./my-script.sh arg1       # run it
bash my-script.sh arg1    # run without exec permission
source lib.sh             # run in the CURRENT shell (also: . lib.sh)

Variables & quoting

name="world"            # no spaces around =
echo "Hello, $name"     # Hello, world
echo "Hello, ${name}!"  # braces mark where the name ends
echo 'Hello, $name'     # single quotes: no expansion → Hello, $name

readonly PI=3.14        # constant
export PATH="$HOME/bin:$PATH"   # make visible to child processes
unset name              # delete variable

today=$(date +%F)       # command substitution (prefer over backticks)
files=$(ls | wc -l)
Always quote variables, as in "$var". Without quotes, Bash splits the value on spaces and expands globs, so rm $file with file="my notes.txt" tries to delete my and notes.txt.

Parameter expansion

Built-in string manipulation, with no need for sed or cut.

file="/home/user/photos/beach.tar.gz"

${file##*/}       # beach.tar.gz     strip longest match from start (basename)
${file%/*}        # /home/user/photos  strip shortest match from end (dirname)
${file#*.}        # tar.gz           strip shortest match from start
${file##*.}       # gz               extension
${file%.*}        # /home/user/photos/beach.tar
${file%%.*}       # /home/user/photos/beach

${#file}          # 31               length
${file:6:4}       # user             substring (offset:length)
${file: -6}       # tar.gz           last 6 chars (note the space)

${file/photos/pics}   # replace first match
${file//o/0}          # replace all matches
${file^^}             # UPPERCASE   (bash 4+)
${file,,}             # lowercase   (bash 4+)

Brace expansion

echo {a,b,c}.txt        # a.txt b.txt c.txt
echo {1..5}             # 1 2 3 4 5
echo {01..10..3}        # 01 04 07 10
mkdir -p project/{src,tests,docs}

Arrays

Indexed arrays

fruits=("apple" "banana" "cherry")
fruits+=("date")               # append

echo "${fruits[0]}"            # apple
echo "${fruits[@]}"            # all elements
echo "${#fruits[@]}"           # length → 4
echo "${!fruits[@]}"           # indices → 0 1 2 3
echo "${fruits[@]:1:2}"        # slice → banana cherry
unset 'fruits[1]'              # remove element

for f in "${fruits[@]}"; do echo "$f"; done

files=(*.txt)                  # array from a glob
mapfile -t lines < file.txt    # array of lines (bash 4+)

Associative arrays (bash 4+)

declare -A ports=([http]=80 [https]=443)
ports[ssh]=22

echo "${ports[https]}"         # 443
for key in "${!ports[@]}"; do
  echo "$key → ${ports[$key]}"
done
[[ -v ports[ftp] ]] || echo "no ftp key"
macOS ships bash 3.2, which has no associative arrays or mapfile. Run brew install bash to get bash 5.

Arithmetic

a=10; b=3
echo $(( a + b ))     # 13
echo $(( a / b ))     # 3   (integer division)
echo $(( a % b ))     # 1
echo $(( a ** 2 ))    # 100
(( a++ ))             # increment
(( count += 5 ))
(( a > b )) && echo "a is bigger"

# Floating point — Bash only does integers; use bc or awk
echo "scale=2; 10 / 3" | bc          # 3.33
awk 'BEGIN { printf "%.2f\n", 10/3 }' # 3.33

Conditionals & tests

if [[ -f "$file" ]]; then
  echo "file exists"
elif [[ -d "$file" ]]; then
  echo "it's a directory"
else
  echo "not found"
fi

# One-liners
[[ -z "$name" ]] && echo "name is empty"
[[ -d "$dir" ]] || mkdir -p "$dir"

# Test a command's success directly
if grep -q "error" log.txt; then echo "found errors"; fi
if ! command -v jq >/dev/null; then echo "jq not installed"; fi
Use [[ … ]] instead of [ … ] in Bash. It handles empty variables safely and supports &&, ||, =~ regex, and glob patterns.

case statements

case "$1" in
  start)
    echo "Starting…" ;;
  stop|halt)
    echo "Stopping…" ;;
  *.tar.gz|*.tgz)
    tar -xzf "$1" ;;
  [0-9]*)

Loops

# Over a list
for name in alice bob carol; do echo "Hi $name"; done

# Over files (glob — never parse `ls`)
for f in *.jpg; do
  [[ -e "$f" ]] || continue     # skip if no matches
  echo "Processing $f"
done

# Ranges
for i in {1..10}; do echo "$i"; done
for (( i = 0; i < 10; i += 2 )); do echo "$i"; done

# While / until
count=0
while (( count < 5 )); do (( count++ )); done
until ping -c1 example.com &>/dev/null; do sleep 1; done

# Infinite loop with break
while true; do
  read -rp "Continue? [y/n] " ans
  [[ "$ans" == n ]] && break
done

break exits the loop and continue skips to the next iteration. Both take a number to act on outer loops, as in break 2.

Functions

greet() {
  local name="${1:-stranger}"   # `local` keeps variables scoped to the function
  echo "Hello, $name"
}
greet "Alice"

# "Return" a value by printing it, then capture with $( )
get_ext() { echo "${1##*.}"; }
ext=$(get_ext "report.pdf")     # pdf

# `return` sets the exit status (0–255), used for true/false
is_number() { [[ "$1" =~ ^-?[0-9]+$ ]]; }
if is_number "42"; then echo "yes"; fi

# All args, arg count
show_args() { echo "$# args: $*"; for a in "$@"; do echo " - $a"; done; }

Arguments & getopts

Short options with getopts

verbose=0; output=""
while getopts ":vo:h" opt; do      # leading ":" = handle errors yourself
  case "$opt" in                   # "o:" = -o takes a value
    v) verbose=1 ;;
    o) output="$OPTARG" ;;
    h) usage; exit 0 ;;
    :) echo "-$OPTARG needs a value" >&2; exit 1 ;;
    \?) echo "Unknown option -$OPTARG" >&2; exit 1 ;;
  esac
done
shift $((OPTIND - 1))              # "$@" now holds the remaining args

Long options (manual loop)

while [[ $# -gt 0 ]]; do
  case "$1" in
    -v|--verbose) verbose=1; shift ;;
    -o|--output)  output="$2"; shift 2 ;;
    --output=*)   output="${1#*=}"; shift ;;
    --)           shift; break ;;
    -*)           echo "Unknown option $1" >&2; exit 1 ;;
    *)            args+=("$1"); shift ;;
  esac
done

Here-docs & substitution

# Here-doc: multi-line input (variables expand)
cat <<EOF > config.ini
user=$USER
home=$HOME
EOF

# Quoted delimiter: no expansion (good for writing scripts)
cat <<'EOF'
echo "$HOME is not expanded here"
EOF

# <<- strips leading TABs, so you can indent the body
if true; then
	cat <<-EOF
	indented with tabs
	EOF
fi

# Here-string
grep -o '[0-9]*' <<< "order 1234"

# Command substitution
now="$(date '+%Y-%m-%d %H:%M')"

# Process substitution: treat command output as a file
diff <(sort a.txt) <(sort b.txt)
while read -r line; do echo "$line"; done < <(find . -name '*.md')

Reading input & files

# Prompt the user
read -rp "Your name: " name
read -rsp "Password: " pass; echo     # -s = silent
read -rt 5 -p "Quick! " ans || echo "timed out"

# Read a file line by line (the correct way)
while IFS= read -r line; do
  echo "→ $line"
done < file.txt

# Split fields (CSV-ish)
while IFS=, read -r name email role; do
  echo "$name <$email> ($role)"
done < users.csv

# Handle filenames with spaces/newlines from find
find . -type f -print0 | while IFS= read -r -d '' f; do
  echo "$f"
done

# Whole file into a variable
content="$(< file.txt)"
IFS= keeps leading and trailing whitespace. -r stops backslashes from being treated as escape characters. Use both every time you read lines.

Exit codes & error handling

CodeMeaning
0success
1general error
2misuse of shell builtin / bad usage
126command found but not executable
127command not found
128+Nkilled by signal N (130 = Ctrl-C, 137 = kill -9)
die() { echo "ERROR: $*" >&2; exit 1; }

[[ -r "$config" ]] || die "Cannot read $config"
cd "$dir" || die "cd failed"

# Check status explicitly
if ! output=$(some_command 2>&1); then
  die "some_command failed: $output"
fi

# Allow a command to fail under set -e
rm -f maybe.txt || true

# Require dependencies
for cmd in curl jq git; do
  command -v "$cmd" >/dev/null || die "Missing dependency: $cmd"
done

# Require root
(( EUID == 0 )) || die "Run as root (sudo)"

Traps & cleanup

tmp="$(mktemp -d)"
cleanup() { rm -rf "$tmp"; }
trap cleanup EXIT                 # runs however the script exits
trap 'echo "Interrupted"; exit 130' INT TERM

# Report the line where an error occurred
trap 'echo "Error on line $LINENO" >&2' ERR

# Simple lock so only one copy of the script runs at once
lock="/tmp/$(basename "$0").lock"
if ! mkdir "$lock" 2>/dev/null; then
  echo "Already running" >&2; exit 1
fi
trap 'rm -rf "$lock"' EXIT

Debugging

bash -n script.sh        # syntax check only, no execution
bash -x script.sh        # print each command as it runs
set -x  … set +x         # trace only one section

# More informative trace prefix
export PS4='+ ${BASH_SOURCE}:${LINENO}: ${FUNCNAME[0]:+${FUNCNAME[0]}(): }'

# Static analysis (strongly recommended)
shellcheck script.sh     # brew install shellcheck / apt install shellcheck

Best practices

  • Start with #!/usr/bin/env bash and set -euo pipefail.
  • Quote every expansion: "$var", "$@", "$(cmd)".
  • Use [[ ]] for tests and (( )) for arithmetic.
  • Declare function variables with local.
  • Send errors and logs to stderr (>&2) so stdout stays clean for piping.
  • Never parse ls. Use globs or find -print0.
  • Use $(…), not backticks.
  • Use mktemp for temp files and clean up with trap … EXIT.
  • Write rm -- "$file" so a filename that starts with - isn't read as an option.
  • Guard dangerous paths: rm -rf "${dir:?}/"* refuses to run if dir is empty.
  • Give risky scripts a dry-run mode, and print a usage message for -h.
  • Run shellcheck on everything.
  • Once a script grows past about 200 lines or needs complex data structures, switch to Python.

sed

sed 's/old/new/' file           # replace first match per line

awk

Cron syntax

# ┌ minute (0-59)
# │ ┌ hour (0-23)
# │ │ ┌ day of month (1-31)
