Basics

Script structureEvery script should start with a shebang and, for most scripts, “strict mode”. Keep logic inside functions and call main at the bottom.Variables & quotingAlways quote variables , as in "$var" . Without quotes, Bash splits the value on spaces and expands globs, so rm $file with file="my…Parameter expansionBuilt-in string manipulation, with no need for sed or cut .ArraysmacOS ships bash 3.2, which has no associative arrays or mapfile . Control flow

Conditionals & testsUse [[ … ]] instead of [ … ] in Bash. It handles empty variables safely and supports && , || , =~ regex, and glob patterns.case statementsMatch a value against patterns: globs, alternatives and fall-through.Loopsbreak exits the loop and continue skips to the next iteration. Both take a number to act on outer loops, as in break 2 .FunctionsDefining functions, local variables, return codes and returning values.
