Archives

CommandPurpose
tar -czf out.tar.gz dir/create gzip tarball
tar -xzf file.tar.gzextract (add -C dir for destination)
tar -tzf file.tar.gzlist contents
tar -cJf out.tar.xz dir/xz compression (smaller, slower)
zip -r out.zip dir/create zip
unzip file.zip -d dest/extract zip
gzip f / gunzip f.gzcompress / decompress a single file
zcat f.gz / zgrep pat f.gzread / search without extracting

To remember the tar flags: create, extract, list, z = gzip, f = file (always last, because the filename follows it).
