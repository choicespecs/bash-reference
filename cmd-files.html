Files & directories

CommandPurpose
ls -lahlist all files, long format, human-readable sizes
cd -go back to the previous directory
pwdprint working directory
mkdir -p a/b/ccreate nested directories
cp -r src destcopy recursively (-a preserves attributes)
mv old newmove or rename
rm -rf dirdelete recursively, no prompt (careful!)
ln -s target linkcreate a symlink
touch filecreate file / update timestamp
chmod 755 f / chmod +x fchange permissions
chown user:group fchange owner
stat filedetailed file info
realpath fileabsolute path
rsync -avh src/ dest/sync directories (add --delete to mirror)
du -sh *size of each item here
df -hfree disk space

find

find . -name "*.log"                     # by name (-iname = case-insensitive)
find . -type f -size +100M               # files over 100 MB
find . -type f -mtime -1                 # modified in the last 24 h
find . -type d -empty -delete            # delete empty dirs
find . -name "*.tmp" -exec rm {} +       # run a command on matches
find . -type f -name "*.sh" -print0 | xargs -0 chmod +x
find . -path ./node_modules -prune -o -name "*.js" -print   # exclude a dir
