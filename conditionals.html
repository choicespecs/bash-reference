Conditionals & tests

if [[ -f "$file" ]]; then
  echo "file exists"
elif [[ -d "$file" ]]; then
  echo "it's a directory"
else
  echo "not found"
fi

# One-liners
[[ -z "$name" ]] && echo "name is empty"
[[ -d "$dir" ]] || mkdir -p "$dir"

# Test a command's success directly
if grep -q "error" log.txt; then echo "found errors"; fi
if ! command -v jq >/dev/null; then echo "jq not installed"; fi
Use [[ … ]] instead of [ … ] in Bash. It handles empty variables safely and supports &&, ||, =~ regex, and glob patterns.

String tests

TestTrue if…
-z "$s"string is empty
-n "$s"string is not empty
"$a" == "$b"strings are equal (!= for not equal)
"$s" == *.txtglob match (no quotes on the pattern)
"$s" =~ ^[0-9]+$regex match; groups go into ${BASH_REMATCH[@]}
