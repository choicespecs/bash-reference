Redirection & pipes

SyntaxEffect
cmd > filestdout to file (overwrite)
cmd >> filestdout to file (append)
cmd 2> filestderr to file
cmd > file 2>&1stdout and stderr to file (order matters)
cmd &> filesame as above (bash shorthand)
cmd > /dev/null 2>&1discard all output
cmd < filefile as stdin
echo "msg" >&2write to stderr (for errors and logs)
cmd1 | cmd2stdout of cmd1 → stdin of cmd2
cmd1 |& cmd2stdout and stderr piped
cmd | tee fileshow output and save it (tee -a appends)

Command chaining

SyntaxRuns cmd2…
cmd1 ; cmd2always
cmd1 && cmd2only if cmd1 succeeded
cmd1 || cmd2only if cmd1 failed
cmd &runs cmd in the background; wait waits for it
( cmd1; cmd2 )in a subshell (a cd there doesn't affect the parent)
{ cmd1; cmd2; }grouped in the current shell
