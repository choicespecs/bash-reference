System & processes

CommandPurpose
ps auxall running processes
ps aux | grep [n]ginxfind a process (the [n] trick hides grep itself)
pgrep -fl namefind PIDs by name
top / htoplive process monitor
kill PIDask a process to stop (SIGTERM)
kill -9 PIDforce kill (SIGKILL)
pkill -f patternkill by name / pattern
jobs / fg / bgmanage shell jobs (Ctrl-Z suspends)
nohup cmd &keep running after logout
lsof -i :8080what's using port 8080
uname -akernel / OS info
uptimeuptime and load average
free -hmemory usage (Linux)
whoami / idcurrent user / groups
env / printenvenvironment variables
which cmd / type cmdwhere a command comes from
time cmdmeasure how long a command takes
watch -n 2 cmdre-run every 2 seconds
crontab -eedit scheduled jobs
systemctl status svcservice status (systemd)
journalctl -u svc -ffollow a service's logs

Cron syntax

# ┌ minute (0-59)
# │ ┌ hour (0-23)
# │ │ ┌ day of month (1-31)
# │ │ │ ┌ month (1-12)
# │ │ │ │ ┌ day of week (0-7, Sun=0 or 7)
# * * * * *  command
0 2 * * *    /path/backup.sh             # daily at 02:00
*/15 * * * * /path/healthcheck.sh        # every 15 minutes
0 9 * * 1-5  /path/report.sh             # weekdays at 09:00
@reboot      /path/startup.sh            # at boot
